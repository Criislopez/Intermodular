# APP de Control de Personal

Este proyecto está dirigido a empresas que cuentan con varios trabajadores bajo contratación y que necesitan registrar su jornada laboral, tener un control sobre los días de vacaciones y tener organizadas a estas personas según los proyectos que se están realizando para tener un mejor seguimiento de los horarios y el personal.

Desde hace unos años, se viene hablando de que será ilegal en España firmar el control de horario con sistemas de papel, Excel y otros sistemas manipulables que dejan a los trabajadores desprotegidos ante la manipulación de los horarios laborales que realizan éstos. 

Este proyecto intenta solucionar este problema a través del fichaje por esta aplicación, que registra de forma real la jornada de 8 horas que realiza el trabajador.


## Funcionalidades
- Registro de jornada laboral: el empleado ficha entrada y salida desde la aplicación. El sistema registra la hora exacta e impide modificaciones posteriores.

- Control de vacaciones: el empleado solicita las vacaciones que quiere coger y se registra los que ha pedido y los que le quedan.

- Gestión de empleados: permite a los administradores dar de alta y de baja a nuevos empleados y asignarles un proyecto, un rol y tener su información principal.

- Asignación a proyectos: permite crear proyectos para asignarlos a los empleados y tener un control sobre el equipo que realizó el proyecto y su líder.
  

## Tecnologías usadas

Para realizar la lógica del programa, se ha utilizado Java con IntelliJ como IDE.

Para la parte gráfica se usó Stitch para hacer el prototipo y JavaFX con Scene Builder para llevarlo a cabo,.

Por último, para finalizar el diseño y darle un toque más moderno, elaboré los estilos con CSS.
